PROGRAMMING EXERCISE 5

Evaluator

Write an evaluator for your language. The evaluator is a Python function that computes the results of a program from its tree.

AST (from PE4)
↓
evaluate
↓
RESULTS

File to Submit

Submit [UP ID username]-evaluator.py, which contains your evaluate function. Use Python 3 and the standard library only.

Function

def evaluate(ast):
    ...   # returns a list with one result per output statement

Return the results. Do not print them. The tree has the same node shapes as in PE4, so the function does not depend on your notation or keywords.

evaluate(("PROGRAM", [
    ("PRINT", ("ADD", ("INTEGER", 2), ("INTEGER", 3))),
    ("PRINT", ("MUL", ("INTEGER", 4), ("INTEGER", 5))),
]))
# [5, 20]

Rules

  • Compute addition, subtraction and multiplication as usual.
  • Truncate division toward zero: 7 / 2 is 3, (0 - 7) / 2 is -3, and (0 - 3) / 2 is -1.
  • Raise ZeroDivisionError("Division by zero") for division by zero. If any statement divides by zero, raise the error for the whole call and return no partial results.

Testing

Put selftest.py in the same folder as evaluator.py and run:

python selftest.py pe5

It does not need your language.json. Your evaluator is tested on trees I provide, not on the output of your parser, so a mistake in PE4 does not cost you points here.

Submission

Submit [UP ID username]-evaluator.py to the PE5 submission bin in Moodle.
