IS 214 · PRINCIPLES OF PROGRAMMING LANGUAGES

Programming exercises

In the first programming exercise you practiced programming in Python. In the second one, you wrote a lexer for a calculator language. In the remaining exercises, you will build a small interpreter for a language that you will design yourself. You will build it in stages, and each stage uses the result of the one before it.

Overview

For example, suppose you design a language called Calcora. A program written in it looks like this:

SHOW SUM(2, 3)
SHOW PRODUCT(SUM(2, 3), 4)

Your interpreter should produce two results, 5 and 20, in that order. You will be able to do this as you work through the programming exercises.

  1. Programming Exercise 3 - Design your own language. Set keywords, notation, and layout rules. Save your choices in language.json. This will be the basis of your next assignments.
  2. Programming Exercise 4 - Write a lexer for your language that breaks a program into tokens, and a parser that organizes the tokens into a tree.
  3. Programming Exercise 5 - Write an evaluator that computes the result of the tree.
  4. Final Interpreter - Combine your lexer, parser and evaluator into one program.

Your language will look different from Calcora, because you choose its design. The stages are the same for everyone.

Checking

Submit each exercise in its own submission bin in Moodle. I will run your files against tests generated from your own language.json. Follow the instructions on each page to test your work before you submit. The deadline for everything is December 19.

Name each file you submit with your UP ID username and a hyphen before the file name. For example, my lexer.py becomes rhborromeo-lexer.py. Keep the original file names in your own folder.
