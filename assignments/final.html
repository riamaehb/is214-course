Files to Submit

Submit one ZIP file named [UP ID username]-interpreter.zip with these five files at the top level. Keep the original file names inside the ZIP, because the imports depend on them.

language.json
lexer.py
parser.py

Use your PE3 to PE5 files, with fixes. interpreter.py is the only new file.

Entry Point

from lexer import tokenize
from parser import parse
from evaluator import evaluate

def run(source, spec):
    tokens = tokenize(source, spec)
    ast = parse(tokens, spec)
    return evaluate(ast)

Make run return a list with one integer for each output statement. Do not print, and do not catch errors. The ValueError, SyntaxError and ZeroDivisionError from your three stages must reach the caller unchanged.

Check Before Submitting

  • Put the five files in one folder, and match the imports to the file names.
  • Make the parser's tree match what the evaluator expects: tuples, with Python integers for integer nodes.
  • Return several results for a program with several output statements.
  • Do not print anything or wait for input.
  • Use the language.json you submitted in PE3.

Testing

Put selftest.py in the same folder as your five files and run:

python selftest.py final
