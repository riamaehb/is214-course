PROGRAMMING EXERCISE 3

Language Design

Design a small calculator language using the form below. The form saves your design in language.json. Download it and submit it as described under Submission.

Language Rules

  • A program has one or more output statements, one per line. Each produces one integer result.
  • An expression is an integer or an operation. Operations can be nested.
  • The operations are addition, subtraction, multiplication and division. Each takes exactly two operands.
  • Integers are digits only. There are no negative literals, but results can be negative.
  • Division truncates toward zero. Division by zero is an error.
  • There are no variables, functions, strings or comments.

See the Language Rules and Conventions page for the full list.
